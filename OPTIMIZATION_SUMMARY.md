## ⚠️ Important Notes

### System Requirements

- **Must Have**: Raspberry Pi 4B (4GB RAM), Python 3.11+, Ollama
- **Recommended**: Active cooling, 64-bit OS, 8GB+ SD card free

### Known Limitations

1. **CPU Governor**: Requires Linux + sudo access
   - Windows/macOS: Skipped (no equivalent)
   - Raspberry Pi: Must run with sudo or manual setup

2. **Ollama q2_K**: Lower quality than q4_K
   - Trade-off: 40% faster, slightly less coherent
   - For most conversations: Not noticeable

3. **faster-whisper**: Different API than openai-whisper
   - Phase 2 script updates code automatically
   - If issues: Check `src/workers/stt_worker.py`

### When to Skip

- **Skip Phase 1 if**: Already using faster-whisper
- **Skip CPU governor if**: Not on Linux/RPi
- **Skip Phase 2 if**: Custom worker modifications

## 🎓 Understanding the Optimizations

### Why faster-whisper?

- Uses CTranslate2 (C++ optimized backend)
- INT8 quantization (4x faster on CPU)
- VAD filtering (skip silence processing)
- Parallel workers (multi-threaded)

### Why Qwen q2_K?

- 2-bit quantization (half the memory of q4_K)
- 40% faster inference on CPU
- Still coherent for voice assistant tasks
- Trade-off: Slightly less creative responses

### Why reduce tokens?

- Voice responses should be concise
- Shorter responses = faster generation
- 60 tokens ≈ 2-3 sentences (ideal for TTS)
- Users prefer quick responses over long ones

### Why TTS caching?

- Greetings/errors repeat frequently
- Pre-synthesis eliminates synthesis latency
- 100-200ms saved on common phrases
- Better user experience (instant response)
